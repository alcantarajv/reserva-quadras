API de Reserva de Quadras

Java 21 · Spring Boot 4 · PostgreSQL. O ponto técnico do projeto é o controle de concorrência — e dá para vê-lo funcionando aqui embaixo.

O problema

Duas pessoas clicam em "reservar" na mesma quadra, no mesmo horário, no mesmo instante. Validar com um SELECT antes do INSERT não resolve: entre a consulta e a gravação existe uma janela em que a outra transação passa, e as duas veem o horário livre.

A garantia está no único lugar sem janela de corrida — uma constraint de exclusão do PostgreSQL (EXCLUDE USING gist). A requisição perdedora recebe 409 Conflict.

Veja acontecendo

O botão cria uma conta, reserva um horário e tenta reservar o mesmo horário outra vez. A segunda tentativa é barrada pelo banco.

Explorar a API

  • Swagger UI — todos os endpoints, com o botão Authorize
  • /v3/api-docs — o spec OpenAPI cru
  • /api/quadras — listagem pública, sem token
O serviço roda no plano gratuito do Render e hiberna quando ocioso: a primeira requisição depois de um tempo parado leva cerca de um minuto para responder.
